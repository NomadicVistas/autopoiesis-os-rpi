# Project Management

## MVP 0.1 - Pairable Frames Device

- Pi boots into setup.
- User connects LAN or Wi-Fi.
- Device registers.
- Device shows pairing code.
- User pairs device online under Profile > Frames.
- Settings sync both ways.
- /frames opens fullscreen.
- Heartbeat works.
- Device appears in online profile.

## MVP 0.2 - Personal Stream

- Active artists.
- Liked artworks.
- Stream preferences.
- Sound preferences.
- Personalized feed.

## MVP 0.3 - Offline Living Frame

- Cache liked artworks.
- Cache recent artworks.
- Cache selected artists.
- Elegant offline fallback.

## MVP 0.4 - Broadcast System

- Admin broadcasts.
- Targeted broadcasts.
- Device polling.
- Delivery logs.

## MVP 0.5 - Managed Device Fleet

- Remote disable.
- Remote update command.
- Restart command.
- Diagnostics.
- Release tracking.

## MVP 1.0 - Production Installer

- One-command install.
- Stable GitHub releases.
- Production cleanup.
- Rollback.
- Tested on physical Raspberry Pi.
